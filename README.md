# 백엔드 개발자

스타트업부터 중견기업까지 다양한 환경에서 모바일 앱, 웹 프론트, 백엔드 개발을 해온 개발자입니다. Clean Architecture와 같은 원칙을 적용하여 지속 가능한 소프트웨어 아키텍처를 설계하고, 유지보수성과 확장성이 뛰어난 시스템을 구축하는 데 전문성을 쌓아가고 있습니다. Python과 JVM 기반의 프레임워크를 활용한 개발 경험을 토대로, 백엔드 개발과 AI 엔지니어링을 병행하며 전문성을 키워가고 있습니다.

AI 엔지니어링이 현대 백엔드 개발자의 핵심 역량이라고 확신하며, 신경망 모델 서빙, AI 파이프라인 구축, 그리고 서비스 최적화에 깊은 관심을 가지고 있습니다. 이 두 영역을 결합하여 더 혁신적인 서비스와 시스템을 만들어가는 데 전념하고 있습니다.

코드 한 줄이 실제 사용자의 삶을 개선할 수 있다는 믿음으로 개발에 임하고 있으며, 사용자 중심의 문제 해결과 사회에 긍정적인 영향을 미치는 서비스를 구축할 때 가장 큰 성취감을 느낍니다. 다양한 분야에서 AI와 백엔드 기술을 접목한 혁신적인 솔루션 개발에 기여하고 싶습니다.

## 🛠 기술 스택

- **언어**: Python, Kotlin, Java, TypeScript, JavaScript
- **프레임워크**: FastAPI, Flask, Spring Boot, Node.js, Vue.js
- **데이터베이스**: MySQL, PostgreSQL, MongoDB, Redis
- **메시지 큐**: Kafka
- **테스트**: JUnit, Pytest
- **클라우드/인프라**: AWS, NCP(Naver Cloud Platform), Docker, Nginx
- **기타**: Grafana, Git

## 🌟 핵심 역량

- 다양한 백엔드 프레임워크를 활용한 확장 가능한 시스템 개발
- 컨테이너 기반 개발 및 배포 환경 구축
- AI 서비스 통합 및 API 개발 경험
- 웹, 모바일 앱, SDK 등 다양한 소프트웨어 개발 경험을 통한 폭넓은 기술 이해도
- 새로운 기술을 빠르게 습득하고 서비스에 적용하는 능력과 열정
